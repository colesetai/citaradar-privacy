# CitaRadar Privacy Policy

**Last updated: October 23, 2026**

CitaRadar is an independent Chrome extension that monitors appointment availability for supported Spanish immigration procedures. It is not affiliated with the Spanish government.

## Information stored locally

CitaRadar stores applicant details, selected procedures and provinces, monitoring preferences, notification settings, and recent monitoring results in Chrome extension storage.

Applicant names and identification numbers are not intentionally included in diagnostic reports.

## Government websites

CitaRadar interacts with official Spanish government appointment websites. Information entered by users may be submitted to those websites when performing appointment checks.

CitaRadar does not automatically complete reservations. Users must finalize bookings themselves.

## Optional diagnostics

With user consent, CitaRadar sends technical diagnostics to PostHog. These may include an anonymous installation identifier, browser and extension versions, operating system, selected province, monitoring outcomes, and technical errors.

Diagnostic reporting can be disabled in the extension settings.

## Optional phone notifications

When enabled, CitaRadar uses ntfy.sh to deliver appointment alerts. Notification requests may contain a randomly generated topic, alert text, and a link to the official appointment website.

Phone notifications can be disabled in the extension settings.

## Data sharing

CitaRadar does not sell personal information.

Information is shared with official government websites as required for appointment checks and with PostHog or ntfy.sh only when the corresponding optional functionality is enabled.

## Data retention and control

Users can remove locally stored information by clearing extension data or uninstalling CitaRadar.

Third-party services may retain information according to their own privacy policies.

## Security

CitaRadar uses HTTPS when communicating with supported external services.

## Children's privacy

CitaRadar is not specifically designed for children. Users should enter applicant information only when authorized.

## Changes

This policy may be updated as CitaRadar evolves.
